Implement

```cpp
int longest_run(const std::vector<int>& a);
```

A *run* is a block of consecutive positions that all hold the same value. Return the length of
the longest run in `a`.

Constraints: `1 <= a.size() <= 100000`, `-10^9 <= a[i] <= 10^9`.

Your solution must run in O(n) time.

Examples: `a = [1, 1, 2, 2, 2, 3, 1, 1] → 3`; `a = [4, 5, 5, 7, 7, 7] → 3`.
