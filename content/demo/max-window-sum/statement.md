Implement

```cpp
int max_window_sum(const std::vector<int>& a, int k);
```

Return the largest sum of `k` **consecutive** elements of `a`.

Constraints: `1 <= k <= a.size() <= 100000`, `-10^4 <= a[i] <= 10^4`.

Your solution must run in O(n) time.

Examples: `a = [2, 1, 5, 1, 3, 2, 4], k = 3 → 9`; `a = [-4, -2, -7, -1, -3], k = 2 → -4`.
