# Licence for donated code and labels

**Owner decision (2026-10-21):** CC0 1.0 Universal is the public-release licence, **only
for a contributor who explicitly opts in**. Private study use is the default and the
outcome of no choice. This remains subject to the institution's intellectual-property and
research-data requirements (see `../institutional-review.md`, question 5).

| Option | Fits anonymous publication? | Notes |
| --- | --- | --- |
| **CC0 1.0** (recommended) | Yes. It requires no attribution, so codes such as `A3` are enough. | Widely used for research datasets. Anyone can reuse the material without conditions. |
| CC BY 4.0 (v1 suggestion) | **Poorly.** Reusers must give attribution "in the manner specified", which conflicts with keeping contributors anonymous. | Creative Commons also advises against its licences for software. |
| MIT, with copyright "VAL1-B contributors" | Mostly. The notice can name a collective rather than individuals. | A software licence, so it fits code, but it is less natural for labels and free text. |
| Private repository only (ADR-009) | — | No publication. Others cannot reproduce the study, but it is lowest risk for contributors. |

Two notes on these options:

- **The licence for the repository's own code does not change.** These choices apply only
  to `eval/independent/`.
- **Each contributor chooses on the consent form.** Material from anyone who does not opt
  in is kept in the private study repository and excluded from the public release. The
  report states how many programs that is. The analysis covers all consented material,
  public or private.

This is a recommendation, not legal advice. If the institution has a policy on research
data or intellectual property, for example that students' work during a degree belongs to
them or to the institution, that policy decides.
