# Practice problem: longest run

Write a function

```cpp
int longest_run(const std::vector<int>& a);
```

that returns the length of the longest block of consecutive equal values in `a`, or 0 if
`a` is empty.

| Input | Output |
| --- | --- |
| `[1, 1, 2, 2, 2, 1]` | 3 |
| `[]` | 0 |

This problem is unrelated to the study problems. It is only for practising the stage-1
form: describe each program's primary error in your own words and give a minimal fix.
