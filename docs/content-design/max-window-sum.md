## 1. Learning objective and contract

Keep a fixed-size window up to date in O(1) per step: add the entering element, remove the
leaving one, and track the best window.

```cpp
int max_window_sum(const std::vector<int>& a, int k);
```

- `1 <= k <= a.size() <= 10^5`, `-10^4 <= a[i] <= 10^4`; every window sum can be negative.
- Input modes `L` (literal) and `R` (generated by a linear rule).

## 2. Error models

| Model | Skill | Error | Detecting tests / groups |
| --- | --- | --- | --- |
| `best_starts_zero` | accumulator_init | Best sum starts at 0, so 0 is returned when every window is negative | 4 / 3 |
| `misses_last_window` | index_range | The slide stops one step early | 3 / 2 |
| `never_subtracts` | update_rule | Never removes the leaving element | 10 / 5 |
| `subtracts_wrong_element` | update_rule | Removes `a[i - k + 1]` instead of `a[i - k]` | 9 / 4 |

## 3. Tests

There are 12 tests: 2 samples (one all-negative), best window last and first, `k = n`, `k = 1`
with positive and negative values, mixed signs, a dip then a rise, a single element, and two
generated arrays of 100000 entries.

## 4. Attribution checks (400 random inputs)

- **Recomputing every window with a start loop `< n - k`** is identical to
  `misses_last_window`. It is the same skill (`index_range`), so the attribution stays.
- **k times the largest element** and **windows of k - 1 elements** are unmodelled; they agree
  with a model on at most 115 of 400 inputs.

## 5. Role and held-out plan

- `recommendable = false`; family `sliding-window`.
- 8 held-out cases: 2 correct, 4 modelled, 2 unmodelled.
